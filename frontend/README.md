# Frontend - CamiGest

Esta é a parte do frontend do sistema CamiGest, contendo as interfaces de usuário.

## Estrutura

- `index.html`: Página principal.
- `src/pages/`: Páginas HTML individuais (dashboard, painel, etc.).
- `src/styles/`: Arquivos CSS.
- `public/`: Recursos estáticos (CSS, JS, imagens).

## Como Usar

Abra `index.html` em um navegador web. Para desenvolvimento, configure um servidor local para servir os arquivos estáticos.

## Tecnologias

- HTML5
- CSS3
- JavaScript (se aplicável)
