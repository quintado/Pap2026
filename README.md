## 📖 Sobre o Projeto

O **CamiGest** é uma plataforma desenvolvida para simplificar a gestão de transportes e logística.

A aplicação permite gerir veículos, entregas e utilizadores através de uma interface intuitiva e de uma arquitetura organizada, garantindo facilidade de manutenção e escalabilidade.

---

## ✨ Funcionalidades

* 🚛 Gestão de veículos
* 📦 Gestão de entregas
* 👥 Gestão de utilizadores
* 🔐 Sistema de autenticação
* 📊 Dashboard com informações gerais
* ⚡ API REST em Node.js

## ⚙️ Instalação

### Clonar o repositório

```bash
git clone https://github.com/SEU_UTILIZADOR/CamiGest.git
```

### Instalar dependências

```bash
npm install
```

### Iniciar o servidor

```bash
npm start
```
