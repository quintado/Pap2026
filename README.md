# CamiGest

Sistema de gestão de caminhões e entregas.

## Estrutura do Projeto

Este projeto está organizado em duas partes principais: backend e frontend.

### Backend
Localizado em `/backend`. Contém o servidor Node.js, APIs, lógica de negócio, banco de dados e configurações.

Para executar:
```
cd backend
npm install
npm start
```

### Frontend
Localizado em `/frontend`. Contém as páginas HTML, estilos CSS e recursos estáticos.

Para executar, abra `frontend/index.html` em um navegador ou configure um servidor local.
